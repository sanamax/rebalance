Спецификация подключения T-Invest MCP Server

Сервис реализует стандарт Model Context Protocol (MCP) поверх официального T-Invest REST/gRPC API v2 (invest-public-api.tinkoff.ru) и экспортирует 3 готовых тула: 

{
  "mcpServers": {
    "tinvest-aegis-rebalancer": {
      "url": "https://your-domain.ru/api.php?action=mcp_rpc",
      "env": {
        "TINVEST_API_TOKEN": "t.xxxxxxxxxxxxxxxxxxxxxxxx",
        "TINVEST_ACCOUNT_ID": "2000012345"
      },
      "tools": [
        "get_tinvest_portfolio",
        "simulate_macro_stress",
        "execute_tinvest_rebalance"
      ]
    }
  }
}
